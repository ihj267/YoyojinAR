## 그림을 연결하거나 수정하기

1. 벽화를 확대하고 손으로 잡아 이동합니다.
2. **벽화 캐릭터 지정**을 켜고 캐릭터에 네모를 그립니다.
3. 아이의 원화를 선택하고 **이 원화와 연결 저장**을 누릅니다.
4. 글은 기존 PDF 인식 결과가 자동으로 표시됩니다. 틀린 부분만 고치고 **내용 저장**을 누릅니다.
5. 기존 연결을 고치려면 벽화의 점이나 **원화 목록 관리**에서 작품을 선택합니다. 원본과 같은 그림인지 확인한 뒤 **위치를 확정합니다**를 체크합니다.

아이 원화와 작가의 벽화 그림을 나란히 보여주려면 벽화의 **네모 영역**이 필요합니다. 점만 찍혀 있는 항목은 네모 영역을 추가해 주세요. 현재 002번은 점 위치만 있습니다.

## 수정 내용을 GitHub에 반영하기

1. 작업실 위쪽 **GitHub 테스트 파일 만들기**를 누릅니다. 작성 중인 내용도 저장한 뒤 업데이트 화면으로 이동합니다.
2. 기본 설정은 **위치가 확정된 작품 전체**입니다. 일부만 넣으려면 **공개 체크한 작품 중 위치가 확정된 작품**을 선택합니다.
3. **최신 작업으로 테스트 파일 만들기**를 누르고 **폴더 반영 완료**를 기다립니다. 원화·답변·벽화 비교 그림이 자동으로 준비됩니다.
4. GitHub Desktop에서 **YoyojinAR → 변경 파일 선택 → Commit to main → Push origin** 순서로 올립니다.
5. 배포가 끝나면 [휴대폰 AR 테스트](https://ihj267.github.io/YoyojinAR/test/)를 새로고침합니다. 상단의 업데이트 시간과 연결 수를 확인하세요.

별도로 **GitHub 업데이트 열기.cmd**를 눌러도 업데이트 화면을 열 수 있습니다. 프로그램은 파일만 준비하며, 커밋과 업로드는 직접 합니다. ‘테스트 파일 만들기’를 누르지 않은 편집은 웹에 반영되지 않습니다.

작업 파일과 교체 전 파일은 자동 백업됩니다. 기존 브라우저의 연결과 공개 체크는 바꾸지 않습니다. 가능하면 같은 브라우저에서 편집하고, 브라우저 데이터를 지우기 전에는 테스트 파일 만들기 또는 JSON 내보내기로 작업을 보관하세요. 최신 작업 파일을 바탕으로 새 브라우저에서도 이어갈 수 있습니다.

## 휴대폰에서 테스트하기

**접속 암호와 왼쪽·가운데·오른쪽 선택 없이** 시작합니다. 10초 캐릭터 안내는 X로 건너뛸 수 있습니다. 카메라로 벽화의 일부를 비추면 39개 인식 구역에서 해당 위치를 자동으로 찾습니다. 한 번에 한 구역을 추적하며 최대 12개 포인트를 표시합니다.

포인트를 누르면 **아이의 원화와 YOYOJIN의 벽화 그림**이 함께 열리고, 아래에 PDF 답변이 표시됩니다. 각 그림을 크게 볼 수 있으며 X로 닫습니다.

첫 인식 자료는 약 **32MB**입니다. 진행률을 보면서 기다리고, 필요하면 취소 후 다시 시작할 수 있습니다. 처음부터 벽화 전체를 한 화면에 담을 필요는 없습니다.

실물 벽화가 없으면 컴퓨터에서 [시험 벽화](https://ihj267.github.io/YoyojinAR/test/test-board.html)를 열고 휴대폰으로 비춰 보세요. 서로 떨어진 부분으로 바꾸어도 구역 선택 없이 자동으로 찾습니다.

합성 영상 9개와 컴퓨터의 자동 구역 전환·비교 보기·닫기·카메라 종료/재시작을 확인했습니다. 실제 휴대폰의 인식 속도, 조명, 사선, 관람객 가림은 현장에서 검증해야 합니다.
